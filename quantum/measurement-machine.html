The measurement machine

A state goes in, one of two lamps lights, and you write down whatever number that lamp displays. Pink is what you prepared. Teal is where you pointed the apparatus. The whole physics is the angle between them.

A Bloch sphere showing a prepared state and a knob axis, feeding two lamps with editable numeric labels, probability bars, and running statistics.

  • Type into the label boxes. Change ±1 to 7 and 3, or to 5 and 5. The percentages do not flinch and the lamps fire identically. Only the mean moves, because the mean is the one quantity that reads your notebook.
  • Move the knob, state fixed. Every knob position is a different question. There is a whole sphere of them.
  • Move the state, knob fixed. The probabilities sweep the same way, because only the relative angle exists.
  • Set them perpendicular, then run ×100. Coin flips. Re-align them and it is deterministic. Same apparatus, same state space. The randomness lives entirely in the relationship.
  • On collapse. After a run the state really has jumped onto the lit lamp's direction. The pink point stays where you put it so that run ×100 means a hundred fresh preparations, not one state measured a hundred times. Those are different experiments.
